## 课程内容安排与学习目标

### 哈希表、映射、集合的实现与特性

**为什么要学习哈希类数据结构？**

- **哈希表（Hash Table）**：
  - 平均 O(1) 的查找、插入、删除
  - 基于哈希函数 + 冲突解决（链地址法、开放寻址）
  - 工程应用最广的数据结构之一
- **映射（Map）**：
  - 键值对存储，快速键查找
  - 常见实现：HashMap、TreeMap
  - 适用于计数、分组、缓存场景
- **集合（Set）**：
  - 存储唯一元素的容器
  - 快速判重、交并差运算
  - 适用于去重和成员检测

### 实战题目解析：有效的字母异位词等问题

**有效的字母异位词：**

- **哈希计数入门**：用数组或 HashMap 统计字符频率
- **空间优化**：26 字母专用数组代替 HashMap

**字母异位词分组：**

- **哈希键设计**：将排序后的字符串作为 key
- **分组聚合**：Map<String, List<String>> 模式

**两数之和：**

- **边查边建**：遍历同时构建哈希表
- **空间换时间**：从 O(n²) 到 O(n)

**核心学习点：**

- 掌握哈希表的工程实现和复杂度分析
- 学会设计合适的哈希键
- 理解空间换时间的核心思想

## 学习路径总结

```
哈希基础（计数、判重）

哈希分组（异位词分组）
    ↓
哈希 + 遍历（两数之和）

综合应用（复杂映射设计）
```
