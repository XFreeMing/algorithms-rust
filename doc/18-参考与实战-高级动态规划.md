## 三、课程内容安排与学习目标

### 1. 动态规划、状态转移方程串讲

**高级 DP 的核心能力：**

- **状态设计进阶**：
  - 多维状态：二维、三维 DP
  - 状态压缩：用位表示状态
  - 多状态共存：同时维护多个相关状态

- **状态转移方程推导**：
  - 从暴力递归出发优化
  - 识别重叠子问题
  - 选择合适的状态维度

### 2. 高级动态规划题目详解

**编辑距离：**
- **字符串 DP 集大成者**
- **状态定义**：dp[i][j] 表示 word1[0..i] 转换为 word2[0..j] 的最少操作
- **三种操作**：插入、删除、替换对应不同状态转移

**最长上升子序列：**
- **O(n log n) 解法**：二分 + 贪心
- **DP 解法**：O(n²)，基础版本

**最长有效括号：**
- **栈 + DP**：结合多种技巧
- **状态定义巧妙**

**最大矩形 / 不同的子序列：**
- **二维 DP / 字符串 DP**
- **复杂状态转移**

**赛车：**
- **BFS + 状态压缩 DP**
- **高级综合应用**

**核心学习点：**
- 掌握复杂状态的设计方法
- 学会推导复杂状态转移方程
- 能够综合多种算法思想解题
