## 三、课程内容安排与学习目标

### 1. 实战题目解析：三角形最小路径和

**三角形最小路径和：**
- **二维 DP 进阶**：三角结构上的路径优化
- **空间优化**：自底向上，O(n) 空间
- **对比一维 DP**：状态定义更复杂

**最大子序和：**
- **一维 DP 经典**：Kadane 算法
- **状态定义**：以当前元素结尾的最大子数组和
- **状态转移**：dp[i] = max(nums[i], dp[i-1] + nums[i])

**乘积最大子数组：**
- **双状态 DP**：同时维护最大值和最小值
- **负数翻转**：负负得正的处理

**零钱兑换：**
- **完全背包问题**：硬币可重复使用
- **状态转移**：dp[i] = min(dp[i], dp[i-coin] + 1)

### 2. 实战题目解析：最大子序列和

**打家劫舍系列：**
- **线性 DP**：相邻约束下的最优选择
- **状态设计**：选/不选当前房屋
- **环形变体**：分类讨论首尾

**买卖股票系列：**
- **多状态 DP**：持有/不持有股票
- **冷冻期、手续费**：增加约束的状态转移

### 3. 高级 DP 实战

**编辑距离 / 完全平方数 / 跳跃游戏：**
- **字符串 DP**：编辑距离是 DP 集大成者
- **数学 DP**：完全平方数结合数论
- **贪心 + DP**：跳跃游戏的双重思路

**核心学习点：**
- 掌握多种 DP 状态设计模式
- 学会空间优化技巧
- 能够处理带约束的 DP 问题

## 四、学习路径总结

```
路径 DP（三角形最小路径和）
    ↓
子数组 DP（最大子序和）
    ↓
背包 DP（零钱兑换）
    ↓
线性 DP（打家劫舍、股票系列）
    ↓
字符串 DP（编辑距离）
```
