# 双指针算法

## 一、核心概念

### 定义与特性
双指针技术是在数组或链表中使用两个指针来解决问题的方法，通过控制指针的移动来降低时间复杂度。

### 算法分类
- **快慢指针**：两个指针移动速度不同
- **对撞指针**：两个指针从两端向中间移动
- **滑动窗口**：维护一个动态窗口

### 时间空间复杂度
- 时间复杂度：通常为 O(n)
- 空间复杂度：O(1)

### 适用场景
- 数组/字符串的搜索和操作
- 链表问题（环检测、相交等）
- 有序数组的查找问题

## 二、核心算法模板

### 快慢指针模板
```python
def fast_slow_pointer(nums):
    slow = fast = 0
    while fast < len(nums):
        # 业务逻辑
        slow += 1
        fast += 2  # 或其他移动规则
    return slow
```

## 三、解题技巧

### 常见模式
1. **数组去重/移动元素**：快慢指针
2. **两数之和类问题**：对撞指针
3. **子串/子数组问题**：滑动窗口
4. **链表环检测**：快慢指针

### 解题套路
1. 确定指针初始位置
2. 明确指针移动条件
3. 处理边界情况
4. 优化空间复杂度

### 注意事项
- 避免指针越界
- 正确处理相等情况
- 考虑空数组/链表
- 理解指针移动的含义

## 五、实战解析

### 题目：移动零（LeetCode 283）

**问题描述：**
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

**解题思路：**
使用快慢指针，慢指针指向下一个非零元素应该放置的位置，快指针遍历数组寻找非零元素。

**代码实现：**
```python
def moveZeroes(nums):
    slow = 0  # 慢指针：下一个非零元素的位置
    
    # 快指针遍历数组
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow] = nums[fast]
            slow += 1
    
    # 将剩余位置填充为0
    while slow < len(nums):
        nums[slow] = 0
        slow += 1
```

**复杂度分析：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)

### 题目：盛最多水的容器（LeetCode 11）

**问题描述：**
给定 n 个非负整数 a1，a2，...，an，每个数代表坐标中的一个点 (i, ai)。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

**解题思路：**
使用对撞指针，从数组两端开始，每次移动高度较小的指针，因为移动高度较大的指针不可能得到更大的面积。

**代码实现：**
```python
def maxArea(height):
    left, right = 0, len(height) - 1
    max_area = 0
    
    while left < right:
        # 计算当前面积
        width = right - left
        current_height = min(height[left], height[right])
        current_area = width * current_height
        max_area = max(max_area, current_area)
        
        # 移动高度较小的指针
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    
    return max_area
```
