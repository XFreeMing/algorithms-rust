## 课程内容安排与学习目标

### 动态规划的实现及关键点

**什么是动态规划？**

- **核心思想**：
  - 将问题分解为重叠子问题
  - 通过记忆化避免重复计算
  - 自底向上或自顶向下求解
- **DP 三要素**：
  - **状态定义**：dp[i] 或 dp[i][j] 代表什么
  - **状态转移方程**：dp[i] 如何由之前的状态推出
  - **初始条件 + 边界处理**
- **DP vs 递归 vs 分治**：
  - DP 处理重叠子问题（子问题不独立）
  - 分治处理独立子问题
  - 递归是 DP 的自然表达方式

### DP 例题解析：最长公共子序列

**不同路径 / 不同路径 II：**

- **二维 DP 入门**：网格路径计数
- **状态转移**：dp[i][j] = dp[i-1][j] + dp[i][j-1]
- **障碍物处理**：边界条件

**最长公共子序列（LCS）：**

- **经典二维 DP**：字符串匹配问题
- **状态定义**：dp[i][j] 表示 text1[0..i] 和 text2[0..j] 的 LCS
- **状态转移**：相等则 +1，否则取 max

**核心学习点：**

- 掌握 DP 问题的建模方法
- 学会状态定义和状态转移方程设计
- 理解一维/二维 DP 的区别

## 学习路径总结

