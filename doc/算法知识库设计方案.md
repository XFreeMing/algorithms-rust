# 算法知识库设计方案

## 🏗️ 知识库架构设计

### 整体原则
- **主题聚合**：相关算法和题目集中在一个文档
- **难度递进**：从基础到高级，循序渐进
- **实用导向**：重点关注面试和实际应用
- **模板化**：统一的文档结构和代码模板

## 📁 一级分类（6大领域）

```
算法知识库/
├── 01-基础数据结构/        # 数组、链表、栈队列等
├── 02-算法思想/           # 双指针、动态规划、贪心等
├── 03-高级数据结构/        # 堆、树、图等
├── 04-专题算法/           # 排序、字符串、数学等
├── 05-系统设计/           # 缓存、限流、分布式等
└── 06-面试宝典/           # 高频题、真题、模板等
```

## 📋 文档粒度标准

### 粒度原则

1. **一个核心算法思想 = 一个文档**
   - 例：`双指针技巧.md` 包含快慢指针、对撞指针、滑动窗口
   - 文档长度：4000-6000字
   - 题目数量：15-25道

2. **一个数据结构类型 = 一个文档**
   - 例：`链表操作.md` 包含单链表、双链表的所有操作
   - 文档长度：3000-5000字
   - 题目数量：10-20道

3. **复杂主题按难度拆分**
   - 例：动态规划拆分为基础和进阶
   - 图论拆分为基础和高级算法
   - 每个文档控制在5000字以内

### 内容密度建议

| 难度级别 | 题目数量 | 详解数量 | 模板数量 |
|---------|----------|----------|----------|
| 入门级  | 3-5道    | 2-3道    | 1-2个    |
| 进阶级  | 5-8道    | 3-4道    | 2-3个    |
| 高级    | 3-5道    | 2-3道    | 1-2个    |

## 📄 标准文档模板

### 核心结构（8个部分）

```markdown

## 一、核心概念
- 定义与特性
- 时间空间复杂度  
- 适用场景
- 核心思想

## 二、算法模板
- 基础模板
- 常见变体
- 代码实现
- 关键要点

## 三、解题技巧
- 识别模式
- 解题套路
- 常见陷阱
- 优化方法

## 四、题目分级
- 入门级(Easy): 3-5道
- 进阶级(Medium): 5-8道  
- 困难级(Hard): 3-5道

## 五、详细解析
- 2-3道重点题目的完整分析
- 包含多种解法对比
- 复杂度分析

## 六、进阶扩展
- 变体问题
- 组合应用
- 实际场景

## 七、练习建议
- 学习路径
- 刷题顺序
- 掌握标准

## 八、参考资料
- 经典书籍
- 在线资源
- 相关链接
```

### 第三阶段：优化完善（2-3周）

## 🔍 质量控制标准

### 文档质量要求
- **完整性**：包含所有8个核心部分
- **准确性**：算法描述和代码实现正确
- **实用性**：模板可直接使用，题目覆盖面试常考
- **一致性**：格式统一，风格一致

### 代码质量要求
- **可读性**：变量命名清晰，注释完整
- **正确性**：通过LeetCode验证
- **优化性**：时间空间复杂度最优
- **通用性**：模板适用于同类问题

## 📊 知识库管理

### 使用建议
1. **新手路径**：基础数据结构 → 双指针 → DFS/BFS → 动态规划
2. **面试冲刺**：高频题 → 公司真题 → 难题突破
3. **专项提升**：选择薄弱环节重点突破

这样的知识库设计既保证了内容的系统性和完整性，又便于日常使用和维护，能够有效支撑算法学习和面试准备。
