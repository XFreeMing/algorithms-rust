## 课程内容安排与学习目标

### 树、二叉树、二叉搜索树的实现和特性

**为什么要学习树结构？**

- **树（Tree）**：
  - 非线性层次结构，描述父子关系
  - 广泛应用于文件系统、DOM、组织架构
- **二叉树（Binary Tree）**：
  - 每个节点最多两个子节点
  - 是各种高级树结构的基础
  - 遍历方式：前序、中序、后序、层序
- **二叉搜索树（BST）**：
  - 左 < 根 < 右的有序结构
  - 查找、插入、删除平均 O(log n)
  - 中序遍历得到有序序列

### 实战题目解析：二叉树的中序遍历

**二叉树的中序遍历：**

- **递归入门**：最基础的树遍历方式
- **迭代实现**：用栈模拟递归过程
- **思维训练**：理解 DFS 的递归本质

**前序 / 后序 / N 叉树遍历：**

- **模板统一**：三种遍历仅调整访问时机
- **泛化能力**：从二叉树扩展到 N 叉树

**核心学习点：**

- 熟练掌握递归和迭代两种遍历方式
- 理解不同遍历顺序的应用场景
- 为后续树的递归问题打基础
